# ASCENDO.LOL · Founder Profiles

Static GitHub Pages site for [ascendo.lol](https://ascendo.lol/).

- Solid-black homepage using the bundled Ascendo logo.
- Download button opens the official Ascendo Discord invite for Client 26.3.
- Founder cards route to `/nagyorru/` and `/k3rlsen/`.
- Profile background media loads only after the visitor presses **enter**, then exposes play/pause and sound controls.
- All assets and page routes are repository-relative; `CNAME` remains the source of the custom domain.
